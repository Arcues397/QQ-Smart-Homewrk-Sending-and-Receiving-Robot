# 电工五班作业收发机器人

A Python-based QQ bot for automated homework collection, packaging, and secure return distribution.

基于 QQ 机器人的班级作业自动收发系统，支持学生提交作业、管理员打包导出、老师返还文件批量导入、学生按身份查询并领取自己的返还文件。
注意：本工程仅用于电子科技大学格拉斯哥学院2025级电子信息工程五班的收发作业，纯粹是收作业太（懒）麻（得）烦（收）而开发的。若要用于自己的班级，请配置 `.env`，在项目根目录放置 `app/student_registry.py` 指定的 Excel 名单。`Sheet1` 的 A 列放学号，B 列放姓名。
机器人启动时会创建所需的数据目录。请将班级名单、绑定记录和作业文件保存在本机。

---

## 项目简介

这个项目用于解决班级作业管理中常见的几个问题：

- 学生提交格式混乱，文件命名不统一
- 不同老师对文件命名模板要求不同
- 学委需要按类别和批次整理大量 PDF
- 老师返还的是整包 zip，人工拆分和分发效率低
- 学生不应该看到别人的返还文件或成绩
- 学委需要快速导出已交 / 缺交名单

---

## 功能特性

### 学生端
- 提交作业信息
- 上传 PDF 文件
- 学号姓名自动校验
- 自动重命名与归档
- 查询并领取返还文件

### 管理员端
- 打包导出作业
- 导入老师返还 zip
- 自动匹配返还文件
- 导出已交名单 / 缺交名单
- 查看重名待确认文件，核对后指定收件人
- 核实并批准身份换绑申请

## 学生使用

私聊机器人发送 `帮助` 可查看当前账号可用的命令。

| 操作 | 消息示例 |
| --- | --- |
| 查看类别和批次 | `作业列表` 或 `作业列表 概率论作业` |
| 获取提交命令 | `提交格式 概率论作业 作业10` |
| 提交作业 | `提交 概率论作业 作业10 <学号> <姓名>`，收到确认后在 10 分钟内发送 PDF |
| 核实最近一次成功提交 | `查提交 概率论作业 作业10` |
| 领取批改文件 | `查询 概率论作业 作业10` |
| 查看绑定或申请换绑 | `我的绑定` 或 `申请换绑 <学号> <姓名>` |

## 管理员使用

以下命令由配置为管理员的 QQ 账号私聊发送。

| 操作 | 消息示例 |
| --- | --- |
| 导出最新提交 | `/打包 概率论作业 作业10` |
| 获取人数、姓名和 CSV 名单 | `/已交 概率论作业 作业10` 或 `/缺交 概率论作业 作业10` |
| 导入批改结果 | `/导入返还 概率论作业 作业10`，随后发送老师的 ZIP |
| 核对重名文件 | `/待确认 概率论作业 作业10`，可在末尾加页码。用 `/查看返还 <返还编号>` 查看附件 |
| 确认收件人 | `/确认返还 <返还编号> <候选学号>` |
| 批准换绑 | 核实学生身份后发送 `/确认换绑 <申请编号> <学号> <姓名>`，申请有效期为 24 小时 |

打包时每人取最新一份 PDF，直接放在 ZIP 根目录。文件名含批次、实交份数和应交份数。机器人首次读取新批次时保存当时的班级名单，打包和缺交统计共用这份名单。

## 核心设计

- openid 自动绑定学号
- 学生只能获取自己的返还文件
- 支持多课程、多批次、多命名模板
- 自动记录提交与返还
